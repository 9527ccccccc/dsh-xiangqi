# 棋局真相由 CLI 持有，网页只是它的一个显示端

`局面` 的唯一真相存在磁盘上的一个对局文件里，由 `xq` CLI 独占读写；网页每 350ms 拉取一份由 CLI 发布的**派生视图**并照它重绘。网页不持有任何权威状态，也不参与裁决——它的本地自由摆棋能力只在「没有 CLI」时生效。

这样定的原因是会话侧的可测性：CLI 不依赖浏览器就能读盘、走子、判胜负，整局棋可以无头跑完来自测；反过来若把真相放在页面里，会话每次读局面都要先问「你浏览器开着吗」，且规则无法测试。

## Consequences

- 数据单向流动：CLI → 派生视图 → 网页。人的着法经对话进入 CLI（ADR-0001 已说明页面无法写盘），所以**人类消息即是回合边界**：人不说话，会话就不会动。
- 派生视图是可丢弃的构建产物，可以随时从真相重新生成，不入版本库。
- 页面必须在派生视图缺失时优雅降级回原有的本地摆棋模式——没有 CLI 时它仍是那个「随意摆放棋子」的单文件。
